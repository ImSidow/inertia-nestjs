# nestjs-vue example

Example app for `inertia-nestjs` using:

- NestJS
- Vue 3
- Vite
- Handlebars
- SSR

## Run

```bash
npm install
npm run build:ssr
npm run serve:ssr
npm run start:dev
```

Pages are `.vue` single-file components in `resources/js/pages/`; type-check them with `npm run typecheck:client`.
